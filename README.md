# Тихая Гавань — интерактивное MVP

Адаптивное демо AI-компаньона для людей, переживающих одиночество или истощение.

## Локальный запуск

```bash
npm install
npm run dev
```

## Подключение LLM

Укажите защищённый backend endpoint в `VITE_LLM_ENDPOINT`. Клиент отправляет JSON:

```json
{
  "systemPrompt": "…",
  "mode": "listener | routine | evening",
  "message": "…"
}
```

Ожидаемый ответ:

```json
{ "reply": "…" }
```

API-ключ провайдера должен храниться только на сервере. Если endpoint не настроен или недоступен, демо автоматически использует локальный сценарный движок.

Для демонстрации заземления отправьте в чате: `Мне страшно, меня накрывает тревога`.

Для демонстрации кризисного маршрута: `Я не хочу жить`.
