# Эйра — интерактивное MVP

Адаптивное демо AI-компаньона для людей, переживающих одиночество или истощение.

## Локальный запуск

```bash
npm install
npm run dev
```

## Подключение настоящего AI на Vercel

Серверный маршрут уже находится в `api/chat.js`; ключ никогда не попадает в браузер.

1. Откройте проект в Vercel.
2. Перейдите в **Settings → Environment Variables**.
3. Добавьте `OPENAI_API_KEY` и вставьте свой API-ключ OpenAI.
4. Необязательно добавьте `OPENAI_MODEL` со значением `gpt-5-mini`.
5. Откройте **Deployments**, выберите последний деплой и нажмите **Redeploy**.

Клиент отправляет на `/api/chat` текущую реплику, режим, выбранное обращение и последние 20 сообщений. Защищённый системный промпт хранится на сервере: он задаёт естественный стиль Эйры и запрещает выдавать её за человека, психолога или терапевта.

Если API недоступен, интерфейс показывает отметку о запасном демо-ответе, а не скрывает проблему.

Для демонстрации заземления отправьте в чате: `Мне страшно, меня накрывает тревога`.

Для демонстрации кризисного маршрута: `Я не хочу жить`.
